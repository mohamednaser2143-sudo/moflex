# MoFlex

The public MoFlex site. Viewers watch **Tales Of The Legend** here.

- `index.html` — home, Shows and Trailers tabs
- `watch.html` — the player
- `episodes/` — the 8 episodes
- `trailers/` — the 8 trailers
- `availability.json` — which episodes and trailers are released (changed from the MoFlex Admin site)
